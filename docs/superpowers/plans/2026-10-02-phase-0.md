## Global Constraints

- No business functionality; listen only on 127.0.0.1; preserve user files.
- No user questions; record decisions and rejected alternatives in DECISIONS.md.
- No node-gyp fallback, TLS bypass or fake validation results.
- English documentation and code; zh-CN/en placeholder UI and the specified font stack.

## Review Focus

- A cold checkout installs without existing project dependencies; incorrect Node versions fail clearly.
- Asset/migration paths remain valid when launched from another working directory.
- Repeated migration preserves data and tests never use real user data.
- Headless startup remains healthy; unknown APIs stay 404; hostile Host/Origin headers fail.
- E2E starts its own server, saves a screenshot and cleans up; remote results need direct evidence.
