# Cura phase 0 design

The specification is AGENTS.md section 4, phase 0, with its cross-cutting requirements in sections 3 and 5. The user explicitly requested stopping after this phase.

Prepare a Node 22/pnpm workspace for a local application: shared Zod contracts, a loopback-only Fastify server, and a React/Vite/Tailwind web scaffold. Production serves the built web assets; development proxies API calls. Use strict TypeScript, local Host/Origin validation and operating-system user directories. The initial native SQLite/Drizzle schema contains infrastructure metadata only. Provide a minimal zh-CN/en placeholder, not business functionality.

Verify native prebuilt installation, repeatable real database migration, unit tests in both applications, real HTTP health, headless Chromium E2E with a screenshot, lint/typecheck/build, clean-clone installation/startup, GitHub CI and tag-triggered Release. Installation is idempotent; persistent state stays outside the checkout. Documents and code use English; user-facing copy defaults to zh-CN.

The user authorized commits and pushes to main and a v0.0.1 tag after verification. If remote access remains blocked, finish independent local work, commit it and report the limitation without claiming a release exists.
