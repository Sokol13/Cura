## Delivered

Cura now provides an offline local image library: create/open libraries, register watched folders without modifying originals, upload to managed Inbox, deduplicate content and retain immutable file versions. PNG, JPEG, WebP, GIF, SVG and AVIF have previews, dimensions, EXIF, dominant colors and image similarity where decoding supports it. Other files remain searchable, taggable and downloadable with generic previews.

The three-column workspace includes virtualized grid/list views, nested logical folders, colored/grouped tags, ratings, notes, batch editing, reversible Trash, saved searches, CJK-aware full-text search and combined format/tag/rating/color/source/date/dimension filters. Embedded SD WebUI and supported ComfyUI fields appear automatically; named Midjourney fields and manual corrections are retained without editing originals.

Preview supports zoom, anchored annotation creation/editing/deletion, adjacent asset navigation, version history and side-by-side comparison. Current previews follow external watched-file replacements; selected historical versions remain stable. Manual generation corrections stay with their archived version. Missing-source indicators preserve access to retained bytes rather than removing the asset.

Chinese/English, dark/light/system themes and layout settings persist. Settings shows thumbnail cache usage and clears/rebuilds previews, including retained historical versions. Diagnostic ZIPs include platform/version/catalog statistics and bounded sanitized logs; startup media errors remain available for diagnosis. Permission failures are recoverable and give platform-specific guidance.

## Limits and follow-up

No unresolved release-blocking bug is known after independent review, regressions and the successful integrated gate. The first remote CI exposed directory-registration and incremental-ingestion failures. Controlled tests reproduced a delayed directory-listing response overwriting a typed path; the fix preserves newer user input. Both previously failing workflows now pass in CI without changing thresholds. The initial CI request trace could not be downloaded, so that causal attribution is supported by the reproduced race and successful correction rather than direct inspection of the original POST body.

- Physical macOS and Windows have not been exercised in this Linux environment. Default browser opening, protected-folder permissions, real long/locked paths, filesystem normalization and display behavior require the user's [ten-minute smoke test](SMOKE_TEST.md). These results must be recorded honestly and incoming bugs take priority.
- Generation extraction is limited to embedded supported formats: unknown/custom Comfy nodes, workflow-only files or ambiguous output branches can be partial. Cura retains raw parameters and parser warnings; it does not infer absent metadata. GIF acceptance covers first-frame thumbnails and SVG uses rasterized previews. Flat images can have fewer than five palette colors.
- Browser upload/replacement limit is 100 MiB per file. Immutable snapshots consume additional disk space. Cache clearing and Trash do not reclaim retained version storage; snapshot garbage collection is not part of v0.1.0.
- Canvas/slots/matrices, brand/CMF workflows, PSD/PDF/video/3D previews, creative-process statistics and neutral whole-library export belong to v0.2.0. Agent automation, Supabase/team features and FCPXML belong to v0.3.0.
- No credentials are needed for v0.1.0. Dependency/native-runtime license terms, including the explicit Sharp exception, remain documented in [DEPENDENCIES.md](DEPENDENCIES.md).

After publication, development continues immediately with TASKS.md Task 7 (boards, slots and matrices), then the rest of v0.2.0. The v0.1.0 report is an intermediate milestone, not a stopping condition.
