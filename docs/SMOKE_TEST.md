# v0.2.0 desktop smoke test

Run on physical macOS and Windows after [SETUP.md](SETUP.md). Allow about **10 minutes after installation/build**; an initial scan can take longer. This is a manual checklist, not a claim that either platform has passed. Record the exact tag/commit, OS and architecture. The [v0.1 report](REPORT-v0.1.0.md) retains earlier acceptance evidence.

Prepare a disposable folder with 200–500 images and a Chinese filename. `node scripts/generate-fixtures.mjs <absolute-new-folder> 300` generates suitable PNGs with SD/Comfy metadata without overwriting files. Keep two visibly different files for replacement. The repository's `e2e/fixtures/rich` contains original GLB/OBJ/PSD/PDF/MP4/MOV fixtures; include `cjk-first-page.pdf` for Chinese text. Back up an existing Cura user-data directory before upgrading; sources in this checklist are disposable, so external edits are intentional.

## Platform and follow-up checks

- **macOS:** Protected-folder denial should name Full Disk Access for the terminal/Node. Grant it and retry. Check Chinese filenames created with NFC/NFD spellings where possible.
- **Windows:** Try a long nested path and a locked/unreadable file. Expect a recoverable error, preserved saved state and usable PowerShell `.cmd` commands. Extract exported filenames including non-ASCII names.
- Open downloaded brand HTML/PDF as actual desktop files. The managed test browser blocks `file:` navigation; automated HTML checks instead render the exact downloaded bytes in an isolated document with networking blocked.
- While an asset preview is open, replace/rename/remove its disposable registered source. New current bytes appear; historical bytes remain available. A missing source is marked without losing retained versions.
- Keep a timeline open, externally replace the current source, then try to finalize the old display. Cura must refresh/report a conflict rather than silently select an unseen replacement.
- Try browser Back/Forward between library/workspaces and Escape from the selected-export dialog; keyboard focus should return to its launcher.
- A normal PDF page with Chinese text should not become a misleading blank preview. Password-protected PDFs and unsupported video codecs should report the limitation. Native video/graphics support depends on the browser/OS; see [PREVIEWS.md](PREVIEWS.md).
- Export bounds are explicit: classic ZIP up to 3.5 GB including metadata and 65,532 distinct payload files. Oversized exports should fail visibly; use smaller selected subsets. Missing/corrupt retained bytes must not produce a successful incomplete archive.

## Report a result

Record pass/fail and the first failing step, tag/commit, OS/architecture, Node/pnpm versions, expected versus actual behavior and terminal output. Include a screenshot and diagnostic ZIP when useful. For startup failures, include the terminal error and relevant logs from SETUP.md. Inspect logs for private filenames/metadata before sharing; do not include credentials.

Desktop results and limitations go into the milestone report. Linux headless Chromium, simulated Windows naming/paths and permission-message unit tests do not substitute for these physical checks. Agent automation, cloud/team synchronization and FCPXML remain P2 checks.
