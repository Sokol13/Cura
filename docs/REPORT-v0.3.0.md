## Limits and user action

- Physical macOS/Windows, protected folders/long paths, desktop browser/video behavior, session-file ACLs and Final Cut Pro import remain [manual smoke checks](SMOKE_TEST.md). Linux, real local Supabase and DTD checks do not establish those outcomes.
- A hosted Supabase project requires applying the supplied migration/policies and configuring Auth/public keys. Hosted quotas, organization policies and deployment configuration are unverified. Cura never uses a service-role key in application/browser configuration; the disposable test seeder uses one privately only to create test accounts.
- The small verified visual model can hallucinate details and did not reliably emit structured JSON. Caption-derived fields remain labelled, reviewable suggestions. No claim of general recognition accuracy, Chinese-language quality or arbitrary-prose extraction is made.
- Structured offline script extraction recognizes documented cues. Deterministic setting documents label absent metadata rather than inventing it. Provider-based extraction requires explicit server configuration and source review.
- FCPXML supports the documented serial-spine subset, PNG/JPEG stills and bounded constant-frame-rate supported MP4/MOV headers. Header validation is not video decoding. Generated packages are local operational artifacts; transfer their ZIP and relink on the editing machine. Cloud does not restore unavailable ready-download paths.
- Existing preview and classic ZIP limits from v0.2 remain. Model tooling, Docker/Supabase CLI, Python/lxml and Apple's downloaded DTD are development/provider prerequisites, not Cura runtime dependencies.

Run the smoke checklist on Mac and Windows and report the first failure with tag/OS and sanitized diagnostics. Incoming desktop bugs take priority. No credentials are required for local use.
